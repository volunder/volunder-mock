# Volunder · mock do front-end

Mock navegável do Volunder, o sistema da Volund para levar um projeto do pedido ao uso. Abra o site e escolha um papel; o
"Ver como", no canto, troca o papel da demonstração. Os dados são de exemplo, de projetos fictícios: nenhum dado real.

Site: https://smmyth-albuquerque.github.io/volunder-mock/
